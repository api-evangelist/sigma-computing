I had a user request where they prep data in an Excel worksheet and wanted to be able to copy and paste column values from that Excel worksheet to a “form” in Sigma that would then transpose the column into a single row in an input table. Traditional forms wouldn’t work because that would require copy and paste one field at a time. I couldn’t find an example and inquired during one of Sigma’s webinars where I got some suggestions to start.
