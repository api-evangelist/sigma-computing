This week, we bring Sigma’s multitenant deployment option to GA, alongside upgrades to the audit logging capabilities for those tenants. Other updates include new support for AI model providers, improvements on the build mode for Sigma Assistant, and API updates. One final feature push that is particularly interesting is a first-class modal for unnesting Array values into net new tables - simplifying many previously custom SQL-based workbooks.
