Hi everyone, Swapnil here from the Sigma Support team. A Sigma user recently reached out with a great use case: they had an input table where users select a country code, and a second table mapping each country code to a list of zones (a one-to-many relationship). They wanted a single-select dropdown in a new input table column that only shows the zones relevant to the country code already entered in that row — cutting the option list down from roughly 3,500 entries to about 14.
